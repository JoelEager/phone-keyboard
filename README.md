# Phone Keyboard

A simple Flask application to enable me to type on a computer using my phone's touch and voice keyboard.

## Installation

### Using requirements.txt
```bash
pip install -r requirements.txt
```

### Editable mode
```bash
pip install -e .
```

## Usage

### Run with Python
```bash
python3 app.py
```

### Run with console script
If installed in editable mode, you can use:
```bash
phone-keyboard
```

## Running Tests
```bash
python3 test_app.py
```
